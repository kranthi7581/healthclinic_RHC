## 📌 Overview

Royal Health Clinic is a **modern, responsive web application** built using **React and Vite**.
It showcases a professional healthcare website with sections like services, gallery, and contact information.

The project focuses on delivering a clean UI, smooth user experience, and mobile-friendly design suitable for real-world clinic websites.

---

## 🚀 Features

* 📱 Fully responsive design (Mobile, Tablet, Desktop)
* 🏥 Clinic information and services section
* 🖼️ Image gallery with fallback handling
* 🎨 Clean and modern UI design
* ⚡ Fast performance using Vite
* 🧩 Reusable React components
* 📌 Structured layout for scalability

---

## 🛠️ Technologies Used

* **React.js** – Component-based UI
* **Vite** – Fast build tool
* **JavaScript (ES6+)** – Application logic
* **CSS / Tailwind (if used)** – Styling
* **Lucide Icons** – UI icons

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash id="clone-hc"
git clone https://github.com/kranthi7581/healthclinic_RHC.git
```

### 2️⃣ Navigate to project folder

```bash id="cd-hc"
cd healthclinic_RHC
```

### 3️⃣ Install dependencies

```bash id="install-hc"
npm install
```

### 4️⃣ Run development server

```bash id="run-hc"
npm run dev
```

### 5️⃣ Build for production

```bash id="build-hc"
npm run build
```
